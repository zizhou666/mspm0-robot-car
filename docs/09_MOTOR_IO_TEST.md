# Motor IO Test 使用说明

该页面用于隔离“电机四路 PWM 驱动”与“编码器/PID”问题。测试直接驱动 r2
参考工程的左右 H 桥输入对，不修改编码器代码、编码器引脚或编码器极性。

## 安全条件

1. 必须架空左右车轮，车体固定，附近没有手指、线束或工具。
2. 使用 PA18/PB21 翻到第 6 页 `Motor IO Test`。
3. 每次只短按一个方向键。输出固定为 350/999，2 秒后自动关闭全部 PWM。
4. 任意时刻短按五向中键，或离开第 6 页，都会立即停止自检。

## 四项测试

| 按键 | 屏幕命令 | 左/右桥输出 |
|---|---|---|
| 上 | L+ | PA7/TIMA0_CC2=350，PA4/TIMA0_CC3=0 |
| 下 | L− | PA7/TIMA0_CC2=0，PA4/TIMA0_CC3=350 |
| 右 | R+ | PA3/TIMA0_CC1=350，PB14/TIMA0_CC0=0 |
| 左 | R− | PA3/TIMA0_CC1=0，PB14/TIMA0_CC0=350 |

屏幕状态依次为 `ARM`、`RUN`、`COAST`、`DONE`。编码器基线与第一次 PWM
输出在同一个 10 ms 控制采样点建立；PWM 关闭后再统计 150 ms 惯性脉冲。
`dL`、`dR` 在 `DONE` 后冻结，此时再记录最终值。开环测试没有速度闭环，电池
电压、摩擦和启动时刻会使不同测试的脉冲数有所差异，脉冲数不要求每次相同。

请分别记录实际转动的是左轮还是右轮、转向，以及 `DONE` 后 `dL`/`dR` 的
数值。L+/L−只应使左轮反向切换，R+/R−只应使右轮反向切换。若某一对输出
不能换向，分别在 MCU 引脚和驱动器输入端测量对应 PWM；MCU 正常而驱动器输入
异常时检查接线/板级通路，两端都正常但电机异常时检查驱动器功率桥或电机。

自检期间只暂停正常闭环的 DIR/NoSig 计时，原故障标志不会被清除。自检结束后
闭环仍保持关闭，必须回到第 5 页重新显式启动。
